# VANTA — Healthcare Growth & Transformation Lab

An independent interactive portfolio case inspired by the skill requirements of a Healthcare & Life Sciences Strategy & Transformation internship.

## Run
Open `index.html` in any modern browser. No build tools, API keys or installation required. Fonts use Google Fonts if available; system fallbacks are provided.

## Experience
1. Mission Control: fictional client brief.
2. Process Diagnosis: interactive lead-to-renewal workflow.
3. Competitive Lens: synthetic capability benchmarks.
4. Opportunity Engine: reweightable initiative prioritisation.
5. Business Case: interactive economic model and sensitivity analysis.
6. Expert Workshop: editable stakeholder insights saved in localStorage.
7. Transformation Path: decision-gated roadmap.
8. Executive Memo: live recommendation with TXT download and browser print.

## Important
Aster HealthTech and all benchmark companies are fictional. Every benchmark score, interview quote, metric, and financial figure is an illustrative assumption. This prototype is not affiliated with Simon-Kucher and does not claim access to their client information. The business case is simplified, undiscounted, and excludes many real-world variables.

## Suggested demo
Start with Process Diagnosis, choose the pricing challenge, compare benchmark capabilities, select an investment posture in Opportunity Engine, change the business case inputs, record a stakeholder insight, and export the executive memo.
